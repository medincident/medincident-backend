# Self (данные текущего пользователя)

Сервис для получения пользователем информации о себе: глобальной роли, занятости в организациях и ролях внутри контекстов (организация, клиника, отделение).

**gRPC:** `SelfQueryService` (query)
**HTTP:** `/v1/me/*`

Все методы требуют валидного Bearer-токена (authn-интерцептор проверяет JWT через Zitadel). Дополнительной ролевой проверки не выполняется — каждый пользователь читает только свои данные.

---

## GetMyIdentity

**gRPC:** `SelfQueryService.GetMyIdentity`
**HTTP:** `GET /v1/me`

### Права доступа

Любой аутентифицированный пользователь.

### Описание

Возвращает глобальные факты об идентификаторе вызывающего:

- `is_system_admin` — является ли пользователь системным администратором.

Метод **никогда** не возвращает `NOT_FOUND`: если пользователь не является системным администратором, возвращается `is_system_admin: false`.

### Ошибки

| Код | Описание |
|---|---|
| `self_identity_failed` | Внутренняя ошибка при обращении к БД |

## ListMyOrganizations

**gRPC:** `SelfQueryService.ListMyOrganizations`
**HTTP:** `GET /v1/me/organizations`

### Права доступа

Любой аутентифицированный пользователь.

### Описание

Возвращает список организаций, в которых у пользователя есть активная (незавершённая) запись о найме. Результат упорядочен по имени организации по возрастанию.

Каждый элемент списка содержит краткую информацию об организации (`OrganizationListItem` из `query/orgstructure/v1`). Если пользователь не состоит ни в одной организации, возвращается пустой список.

### Ошибки

| Код | Описание |
|---|---|
| `self_orgs_failed` | Внутренняя ошибка при обращении к БД |

## GetMyEmployment

**gRPC:** `SelfQueryService.GetMyEmployment`
**HTTP:** `GET /v1/me/organizations/{organization_id}/employment`

### Параметры

| Поле | Тип | Правила |
|---|---|---|
| `organization_id` | string | required, uuid |

### Права доступа

Любой аутентифицированный пользователь (только для своей записи).

### Описание

Возвращает карточку сотрудника (`EmployeeCardView` из `query/membership/v1`) для активной записи найма вызывающего в указанной организации. Запрос аналогичен `EmployeeReader.Get`, но не требует прав администратора — пользователь всегда может получить собственную карточку.

Возвращает `NOT_FOUND`, если пользователь не является активным сотрудником данной организации.

### Ошибки

| Код | Описание |
|---|---|
| `self_employment_not_found` | Пользователь не является активным сотрудником организации |
| `self_employment_failed` | Внутренняя ошибка при обращении к БД |

## GetMyOrganizationRole

**gRPC:** `SelfQueryService.GetMyOrganizationRole`
**HTTP:** `GET /v1/me/organizations/{organization_id}/role`

### Параметры

| Поле | Тип | Правила |
|---|---|---|
| `organization_id` | string | required, uuid |

### Права доступа

Любой аутентифицированный пользователь (только для своей занятости).

### Описание

Возвращает булевые флаги именованных ролей вызывающего в рамках указанной организации:

- `is_org_admin` — является ли пользователь администратором организации;
- `is_org_head` — является ли пользователь руководителем организации;
- `is_org_dispatcher` — является ли пользователь диспетчером организации.

Возвращает `NOT_FOUND`, если пользователь не является активным сотрудником данной организации.

### Ошибки

| Код | Описание |
|---|---|
| `self_org_role_not_found` | Пользователь не является активным сотрудником организации |
| `self_org_role_failed` | Внутренняя ошибка при обращении к БД |
